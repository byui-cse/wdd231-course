## Cross-cutting practice: Responsible AI-assisted development

Complete this section whenever you use AI. It does not require a separate competency pass-off.

| Practiced | Evidence note or link |
| --- | --- |
| [ ] Ask focused questions for explanations, examples, debugging hypotheses, or comparisons. |  |

| [ ] Check AI suggestions against documentation, tests, experiments, and observed behavior. |  |
| [ ] Reject suggestions that are incorrect, insecure, inaccessible, or inappropriate. |  |
| [ ] Explain the final code and identify which decisions are your own. |  |
